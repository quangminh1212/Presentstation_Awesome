# 增强版 Markdeep 幻灯片生成器

这是一个基于 [Markdeep](https://casual-effects.com/markdeep/) 和 [markdeep-slides](https://github.com/doersino/markdeep-slides) 的高度定制化幻灯片制作工具。它旨在通过简单的 Markdown 语法，帮助您快速创建功能丰富、样式精美的演示文稿。

本项目在原有基础上进行了大量优化和功能增强，尤其侧重于提升实用性和视觉表现力。新增了包括但不限于**自动导航栏、自动目录、自定义比例双栏、大纲逐条播放、Obsidian Callout 语法兼容**等现代化功能。

## ✨ 核心功能

- **自动导航与目录 (Auto Navigation & TOC)**: 自动根据一级标题（或自定义标记）生成顶部导航栏和目录页。
- **章节标题显示 (Chapter Title Display)**: 在每个二级标题（H2）页面左下角自动显示其所属的一级标题（H1）。
- **逐条播放 (Incremental Display)**:
    - **大纲播放**: 幻灯片内的列表可以逐条呈现。
    - **自定义分步**: 使用简单的语法精确控制页面上任何元素的出现顺序，支持淡入以及左滑/右滑/上升/缩放四种方向动效。
- **多栏卡片布局 (Columns)**: 支持自定义各栏的宽度比例，最多支持 4 栏（自动排成 2×2）。
- **报刊式分栏 (Newspaper Flow)**: 同一段文字用 CSS 多栏布局自动断行、流入下一栏，效果类似报纸整版排版。
- **富文本卡片组件**: 引用卡片、数字/KPI 卡片、翻转卡片（点击才翻面，文字自动缩放避免出界）、编号徽标前缀等更多排版方式。
- **嵌套围栏语法 (Nested Fenced Blocks)**: 支持多层嵌套的 `:::` 围栏块，可使用更多冒号（如 `::::` 或 `:::::` ）来包裹内层块。
- **可视化图表 (Visualizations)**: 支持在 Markdown 中嵌入 Chart.js、ECharts 与 Mermaid 图表块。
- **全局概览模式 (Overview Mode)**: 按 `O` 键可切换到缩略图网格视图，快速浏览和跳转到任意幻灯片。
- **思维导图播放模式 (Mindmap Mode)**: 按 `M` 键把整份幻灯片变成一张可播放的思维导图，方向键（含翻页笔）顺序播放、`ESDF` 在节点间自由穿梭，被选中的节点展开为完整幻灯片，其余节点只留标题。
- **Obsidian Callout 兼容**: 完美支持 Obsidian 风格的 `[!NOTE]` 标注块语法，12 种类型均有独立配色和左侧图标。
- **列表标注 (List Admonition)**: 为列表项添加特定前缀，即可实现不同颜色的高亮。
- **字号控制 (Font Size Control)**: 可通过简单标记将单张幻灯片切换为小号或微号字体。
- **6 套内置主题**: `simple`、`deepsea`、`serif` 三套经典主题，以及 `claude`（暖色卡片风）、`xiangshui-blue`、`shaoshan-red`（湘潭大学校色，正式高校风格）三套现代主题。
- **页眉 Logo (Logo)**: 用 `logo:` / `logo1:` 指令为标题页、大标题页和普通内容页分别配置右上角的 logo 图片。
- **导出带书签的 PDF**: 提供 [export-pdf.sh](export-pdf.sh) 脚本，导出的 PDF 自带两级可点击书签（对应一级/二级标题），阅读器侧边栏即可跳转。

## 📖 功能详解

### 1. 自动导航与目录

系统会智能地为你创建导航和目录。

- **定义章节**: 在文档中，使用 `== 章节名 ==` 语法来定义一个章节的开始。
- **自动回退**: 如果没有找到 `==` 标记，系统会自动将所有一级标题（H1）作为章节。如果连 H1 都没有，则会使用二级标题（H2）。
- **效果**:
    - **目录页**: 自动在标题页后生成一个可点击的目录页。
    - **顶部导航栏**: 在每张幻灯片顶部生成一个导航栏，高亮当前所在章节，并可点击跳转。
- **目录分栏**: 目录页默认单栏显示，鼠标悬停时右上角会出现一个 `=`/`≡` 切换按钮可以临时切一栏/多栏——但这个切换只是当前页面的临时状态，刷新或用无头浏览器导出 PDF（见下文"导出带标题书签的 PDF"）时都不会保留。如果想固定用多栏，在文档最前面（标题下方，和 `logo:` 同一位置）单独一行写 `toc-columns: multi`；不写则保持默认单栏，等价于 `toc-columns: single`。该指令行本身会从正文中自动去除。

**示例**:
```markdown
==第一章：引言==

# 这是一个H1标题

它不属于任何章节，但其后的H2页面会显示它作为章节标题。


==第二章：核心概念==

## 这是一个H2标题

这张幻灯片的顶部导航栏会高亮 "第二章：核心概念"。
```

### 2. 章节标题显示

为了在浏览时保持上下文清晰，当一张幻灯片以二级标题（H2）开头时，其左下角会自动显示它所属的一级标题（H1）内容。

**示例**:
```markdown
# 第一章：计算机基础

本页是章节封面。

---

## 1.1 冯·诺依曼体系结构

这张幻灯片的左下角会显示 "第一章：计算机基础"。
```

### 3. 逐条播放 (Builds)

#### 全局大纲播放

在幻灯片中任意位置加入 `[incremental]` 和 `[incremental-flat]`标记，该幻灯片中的所有列表项将会逐条出现。

**示例**:
```markdown
## 议程

[incremental]

- 背景介绍
- 方案分析
- 总结与展望
```

#### 自定义分步播放

使用 `:::` 围栏语法，可以精确控制页面上任何元素的出现。

- `:::incremental` 或 `:::appear`: 块内的每个顶级元素（段落、列表、图片等）将成为一个步骤。
- `:::appearN`: 通过数字 `N` 指定出现的顺序。数字越小，越先出现。
- `:::incremental-flat`: 块内的列表项会逐个出现。

**示例**:
```markdown
:::appear1
第一步出现的内容。
:::

:::appear3
第三步出现的内容。
:::

:::appear2
第二步出现的内容。
:::
```

### 4. 多栏卡片布局

使用 `:::columns:::` 围栏包裹内容，栏与栏之间用 `+++`（三个加号）分隔。默认是等宽比例，最多支持 4 栏，超过 3 栏会自动排成 2×2。

要自定义宽度比例，在 `:::columns` 后面加 `N:M`（各栏依次对应）。

**示例**:
```markdown
## 双栏对比

:::columns 2:1

**左侧内容（占 2/3 宽度）**

- 优点一
- 优点二

+++

**右侧内容（占 1/3 宽度）**

- 缺点一
- 缺点二

:::
```

每一栏默认会带浅灰底色和圆角边框；如果栏内含有图片、图表（含 Chart.js/ECharts 等 canvas 图表）、SVG、视频或 Callout，该栏会自动去掉底色、边框和阴影，避免双重卡片感。

如果某一栏的内容是"带子列表的顶层列表项"（如 `- 标题` 下面缩进一层 `- 内容`），根节点文字会自动提升为该卡片的标题（加粗、主题强调色），子列表则作为正文大纲展示在标题下方，不需要额外标记；没有子列表的顶层列表项照常渲染为普通列表。

> **注意**：`+++` 分隔符后面必须跟一个空行，否则后面那一栏的内容会被 Markdeep 当作上一段的续行处理，导致列表渲染失败。

### 4.5 大纲自动转多栏 (`:::listcolumn:::`)

如果你的内容本来就是一份多级大纲（一级条目是标题，下面缩进的子条目是要点），不需要手写 `+++` 分隔——用 `:::listcolumn:::` 围栏包裹后，每个**一级列表项**会自动变成独立的一栏：条目自身文字变成卡片标题，缩进的子列表变成该卡片的正文大纲。栏数由一级条目数量自动决定：≤3 个单行排列，超过 3 个则每行自动排 2 栏（换行规则与 `:::columns:::` 相同）；暂不支持自定义宽度比例。

**示例**:
```markdown
:::listcolumn

- 动态驾驶能力要求
    - 必须达到"合格且专注"的驾驶员水平
    - 一般事故率不得高于 $10^{-4}$ 次/小时

- 全生命周期安全管理
    - 覆盖设计、研发、生产、测试、部署及售后全过程
    - 建立运行数据实时监控体系

- L3 硬件与接管规范
    - 必须装备驾驶员监测系统（DMS）
    - 系统无法处理危险工况时至少提前 10 秒提醒接管

:::
```

上面的例子会生成 3 栏，"动态驾驶能力要求""全生命周期安全管理""L3 硬件与接管规范"分别作为三张卡片各自的标题。如果某个一级条目没有子列表，该卡片就只显示标题，没有正文。

**兼容写法**：如果你压根没有加任何 `:::columns:::` / `:::listcolumn:::` 围栏，只是在幻灯片正文里直接写了 `+++` 分隔符，Markdeep-Slides 也会自动把这一页拆成多栏（效果等同于把正文内容整体包进 `:::columns:::`），栏内同样应用"顶层列表项自动升级为卡片标题"的规则。这页最前面的标题（`#`/`##`）会保留在栏外继续当页面标题，不会被拆进第一栏。这个写法是为了兼容早期直接手写 `+++` 分隔符、没有意识到要加围栏的幻灯片，正式写法仍然推荐显式使用 `:::columns:::` 或 `:::listcolumn:::`。

### 5. Obsidian Callout 语法

直接使用 Obsidian 的 Callout 语法，它们会被渲染成美观的标注块，标题左侧带一个统一浅灰色的 Unicode 图标（不是彩色 emoji，方便用 CSS 统一染色）。

Markdeep 原生的 `!!! 类型: 标题` 围栏语法也同样支持，二者共用同一套配色和图标系统，可以按喜好混用。

**支持的类型**（每种都有独立配色 + 图标）：

| 类型 | 配色 | 图标 |
|---|---|---|
| `note` / `info` | 石板蓝 | ✎ / ℹ |
| `tip` / `success` | 鼠尾草绿 | ✱ / ✓ |
| `question` | 灰紫 | ? |
| `warn` / `warning` | 琥珀 | ⚠ |
| `danger` | 陶土红 | ‼ |
| `error` | 陶土红 | ✕ |
| `bug` | 陶土红 | ◆ |
| `example` | 暖灰褐 | ☰ |
| `quote` / `todo` | 青灰绿 | ❝ / ☐ |

> 全部 12 种类型的独立配色目前在 `claude`、`xiangshui-blue`、`shaoshan-red` 三套主题下最完整；`simple`、`deepsea`、`serif` 只对 `tip`/`warning`/`error` 三种类型上色，但图标在全部 6 套主题下都会显示。

**示例**:
```markdown
> [!NOTE] 这是一条笔记
>
> 你可以在这里写下笔记内容。

> [!WARNING] 这是一个警告
>
> 请注意相关风险。
```

### 6. 列表标注 (List Admonition)

通过在列表项的开头添加特殊符号，可以快速高亮该行。

- `!` : 红色
- `?` : 橙色
- `&` : 蓝色
- `%` : 绿色
- `@` : 紫色

**示例**:
```markdown
- 普通列表项
- ! 这是一个重要的红色警告
- ? 这是一个需要思考的问题
```
*注意：符号与文本之间需要一个空格。*

### 7. 字号控制

如果某张幻灯片内容过多，可以使用标记来缩小字体。

- `[small-text]`: 使用小号字体。
- `[tiny-text]`: 使用微号字体。

**示例**:
```markdown
## 一张内容很多的幻灯片

[small-text]

这里可以放入大量文字，它们会以较小的字号显示，以适应页面。
...
```

也可以使用围栏语法自定义字号

```

## 使用围栏语法自定义幻灯片不同元素的字号

:::big

文字变大

:::


文字正常

:::small

文字变小

:::


:::tiny

文字更小

:::

```

### 8. 嵌套围栏语法 (Nested Fenced Blocks)

当你需要在一个围栏块内部再使用围栏块时，可以使用更多的冒号来区分层级。外层使用更多冒号，内层使用较少冒号。

**规则**：
- 外层围栏使用 N 个冒号（如 `::::`）
- 内层围栏使用少于 N 个冒号（如 `:::`）
- 结束标记的冒号数量必须与开始标记相同

**示例**：
````markdown
::::columns
左侧内容

:::appear1
这部分会先出现
:::

+++

右侧内容

:::appear2
这部分会后出现
:::

::::
````

这个例子展示了在 `:::columns:::` 布局内部嵌套使用 `appear` 块。

### 9. 全局概览模式 (Overview Mode)

在演示过程中，你可以随时按 **`O`** 键进入概览模式，以网格形式查看所有幻灯片的缩略图。

**功能特点**：
- 所有幻灯片以缩略图网格排列
- 当前幻灯片以红色边框高亮显示
- 悬停时显示蓝色边框和阴影效果
- 点击任意缩略图可跳转到该幻灯片
- 再次按 `O` 键或点击缩略图可退出概览模式

**键盘快捷键**：
| 按键 | 功能 |
|------|------|
| `O` | 切换概览模式 |
| `M` | 切换思维导图模式 |
| `F` 或 `Esc` | 切换全屏演示模式 |
| `→` / `↓` / `Space` / `PageDown` | 下一页 |
| `←` / `↑` / `PageUp` | 上一页 |
| `.` | 黑屏 |
| `N` | 打开演讲者备注窗口 |
| `T` | 计时器开始/重置 |

### 9.5 思维导图播放模式 (Mindmap Mode)

在任何时候按 **`M`** 键，整份幻灯片会变成一张**可播放的思维导图**：当前节点展开成一张完整的幻灯片卡片（图表、动效、翻转卡片全部照常工作），其余节点退到背景里，只显示标题。再按一次 `M` 回到普通视图，停在你最后停留的那一页。

**层级从文档结构自动推导**，不需要任何额外语法：

```
演示标题（第一张幻灯片）
└─ 章节        ==章节名==
    └─ 小节     # 一级标题
        └─ 幻灯片  ## 二级标题
            └─ 续页  用 --- 分出的、没有标题的页面
```

- 如果 `==章节名==` 后面紧跟一个**同名**的一级标题，两者会合并成同一个节点，不会多出一层重复的层级。
- 如果某个 `==章节名==` 没有对应的一级标题，它会成为一个「虚拟章节节点」，选中时显示章节大标题和本章统计。
- 没有写 `==` 标记时，自动退回到用一级标题（或二级标题）作为章节，与导航栏、目录页的规则完全一致。

**导航方式**——方向键负责**顺序播放**（和普通放映模式、以及翻页笔的按键完全一致），`ESDF` 负责在树里**自由穿梭**（只在导图模式下生效，普通放映时不影响任何操作）：

| 按键 | 功能 |
|------|------|
| `→` `↓` / `Space` / `PageDown` | 顺序播放：先逐步揭示本页的分步内容，再跳到下一个节点 |
| `←` `↑` / `Shift+Space` / `PageUp` | 顺序回退 |
| `S` | 回到上一级（父节点） |
| `F` | 进入下一级（回到上次访问过的子节点） |
| `E` `D` | 在同级节点之间切换，走到头会自动进入相邻分支 |
| `V` | 只看标题 / 展开幻灯片：把当前展开的幻灯片收回成标题节点，整张图变成纯标题的思维导图；再按一次恢复 |
| `R` | 展开全部 / 只看当前分支：一次性摊开所有节点看全局结构，再按一次折回当前分支 |
| `B` | 夜间 / 日间：切换导图自己的底色（HUD 上也有一个「☾ 夜间」按钮） |
| `A` / `Home` | 回到根节点 |
| `G` | 切换全屏播放（在导图模式下代替 `F`） |
| `Enter` | 退出导图并全屏放映当前这一页 |
| `Esc` | 退出导图，停在当前这一页 |
| `C` / `X` / `Z` | 放大 / 缩小 / 恢复默认缩放 |

**翻页笔**：只有前进 / 后退两个键的翻页笔（无论它发的是 `→`/`←`、`↓`/`↑` 还是 `PageDown`/`PageUp`）在导图模式下直接可用，就是上表的顺序播放 / 顺序回退，和普通放映模式下的行为一致——手上不用切换任何东西，整份导图可以像普通幻灯片一样一路按到底。

也可以直接用鼠标：单击任意节点跳到该节点——鼠标只负责「选中节点」这一件事，单击当前节点（以及在它展开的幻灯片里点任何地方）都不会有额外动作，展开 / 收起走 `V`，放映当前页走 `Enter` 或 HUD 上的「放映此页」按钮，都不会误触；拖动空白处平移画布，滚轮上下左右平移，`Ctrl`（或触控板双指捏合）缩放。

按 `V` 可以在两种视图之间来回切换：默认视图里当前节点展开成完整幻灯片，按下后收回成一个高亮的标题节点，整张图变成纯标题的思维导图——适合讲解结构、回顾脉络，此时按键照常在节点间移动，按 `Enter` 仍然可以直接放映当前这一页。

导图默认只展开你当前所在的那条分支——路径上每一级都会列出全部同级节点，其他分支折叠成一个带数字的小徽标，因此几十页的长幻灯片也不会糊成一堵墙。需要看全局时按 `R` 摊开所有节点（配合 `V` 和 `X` 就是一张完整的纯标题思维导图），再按一次折回。

配色默认跟随主题的明暗和标题色，也可以随时按 `B`（或点 HUD 上的「☾ 夜间 / ☀ 日间」按钮）手动切换：暗背景在关灯的会场里看结构更省眼，亮背景在投影仪上更清楚。这个开关**只改导图自己的皮肤**——底色、连线、节点边框、卡片外框和 HUD——展开的那张幻灯片仍然是它在主题里本来的样子，一个像素都不动。手动切换过之后就以你的选择为准，退出导图再进来也记得住（刷新页面则回到跟随主题）。

### 10. 可视化图表

在 Markdown 中插入以 `chart:` 开头的代码块，渲染器会自动把代码块替换为图表，并按需加载外部库。

支持类型：

| 类型 | `chart:` | 配置内容 |
|------|--------------|----------|
| Chart.js | `chartjs` | Chart.js config JSON |
| ECharts | `echarts` | ECharts option JSON |
| Mermaid | `mermaid` | Mermaid 文本定义 |

示例：

````markdown
```json
chart: echarts
height: 12rem

{
  "xAxis": { "type": "category", "data": ["一月", "二月", "三月"] },
  "yAxis": { "type": "value" },
  "series": [
    { "type": "line", "data": [12, 18, 25] }
  ]
}
```
````

Mermaid 使用文本图定义：

````markdown
```text
chart: mermaid

flowchart LR
    A[输入] --> B[提炼]
    B --> C[幻灯片]
```
````

注意：

- JSON 必须是合法 JSON，不能包含注释或尾逗号。
- 复杂统计图优先用 ECharts；基础折线、柱状、散点可用 Chart.js。
- 复杂网络图可用 ECharts 的 `graph` 系列。
- 示例模板见 `chart-template.html`。

### 11. 主题系统

在 `markdeepSlidesOptions.theme` 中填入主题名即可切换，也可以填自定义 CSS 文件路径（如 `theme: "./my-theme.css"`）：

| 主题名 | 说明 |
|---|---|
| `simple` | 默认主题，白底 + 蓝色标题条，扁平清爽 |
| `deepsea` | 深色主题，藏青底 + 白色大字标题 |
| `serif` | 衬线字体主题，手写感标题（旋转角度、小型大写字母） |
| `claude` | 暖色卡片风格，米色背景 + 陶土色强调色，圆角卡片、柔和阴影 |
| `xiangshui-blue` | 湘潭大学"湘水蓝"校色（`#004290`），正式高校风格：白底、校色标题条、扁平化 Callout |
| `shaoshan-red` | 湘潭大学"韶山红"校色（`#9F191E`），正式高校风格，配色方案与 `xiangshui-blue` 相同、仅主色不同 |

`claude` / `xiangshui-blue` / `shaoshan-red` 三套主题额外为下面介绍的引用卡片、KPI 卡片、翻转卡片、报刊分栏做了主题化配色；`simple` / `deepsea` / `serif` 会用这些组件的中性默认样式（同样可用，只是没有专属配色）。

### 12. 引用卡片

使用 `:::quote 作者:::` 围栏语法，把一句话做成视觉分量很重的大字引用，自动在右下角显示来源。作者参数可省略（`:::quote:::`），此时不显示落款行。

**示例**:
```markdown
:::quote 史蒂夫·乔布斯

求知若饥，虚心若愚。

:::
```

### 13. 数字/KPI 卡片

使用 `:::stat:::` 围栏语法，把内容渲染成"大数字 + 一行说明"的卡片：围栏内第一段文字会被当作数字（自动放大加粗），后面的段落作为说明文字。配合 `:::columns:::` 可以并排展示多个指标。

**示例**:
```markdown
:::columns

:::stat

128%

YoY 增长

:::

+++

:::stat

42

新增客户

:::

:::
```

### 14. 编号徽标前缀

在列表项开头写 `1)`（半角右括号）或圆圈数字 `①`-`⑳`，会被渲染成带圆形底色的步骤序号，同时自动去掉该行原本的项目符号（`•`/`–`/`●`），适合步骤、流程类内容。

**示例**:
```markdown
- 1) 第一步：明确目标
- 2) 第二步：拆解任务
- ③也可以直接用圆圈数字
```

### 15. 报刊式分栏

使用 `:::flow N:::`（`N` 为栏数，可省略，默认 2 栏），把一段较长的文字用 CSS 多栏布局自动断行、流入下一栏，效果类似报纸整版排版。

和 `:::columns:::` 的本质区别：`columns` 是把内容手动拆进独立卡片（用 `+++` 分隔左右两栏各自的内容）；`flow` 是**同一段文字**自动在栏与栏之间断开、继续往下读，不需要手动拆分内容，也不会被切成"要点"。

**示例**:
```markdown
:::flow 2

一整段很长的正文，会像报纸一样自动断开、流入下一栏，而不需要人工拆分成独立的卡片……

:::
```

### 16. 翻转卡片

使用 `:::flip 高度:::`，正反两面用 `+++` 分隔，**点击卡片（或聚焦后按回车/空格）才会翻面，不会自动翻转**，适合问答型内容。

- 高度参数可选，支持 `px`/`rem`/`em`/`vh`/`%` 单位，不写则默认 `15rem`。
- 正反两面的文字会根据卡片实际尺寸自动缩小字号避免出界，不会出现滚动条；行距固定为字号的 1.5 倍，字号无论怎么缩都不会显得行间距过松或过挤。

**示例**:
```markdown
:::flip 10rem

**问：什么是幂等？**

+++

**答：** 同一操作无论执行一次还是多次，产生的效果都相同。

:::
```

### 17. 多方向进场动效

除了 `:::appear:::`（淡入）、`:::appearN:::`（指定顺序）之外，还支持四种带方向的进场变体，用法完全一样（同样支持点击逐步揭示，也可以和 `appearN` 一样用于自定义分步播放的顺序控制）：

- `:::appear-left:::` 从左滑入
- `:::appear-right:::` 从右滑入
- `:::appear-up:::` 从下方升起
- `:::appear-scale:::` 缩放浮现

方向位移只在演示/播放模式下生效；草稿编辑视图里只是普通淡入淡出（保持半透明但不产生位移），不会看起来"跑位"。

### 18. 结束页 / 致谢页

使用 `:::closing:::` 围栏语法，把某一整张幻灯片标记为结束页：内容自动垂直居中，同时隐藏该页的顶部导航栏、页码和进度条，效果和标题页（第一张幻灯片）一样干净，适合放"谢谢观看"之类的收尾内容。

- 只影响该围栏所在的这一整张幻灯片；请确保 `:::closing:::` 是这张幻灯片里唯一/最外层的内容（一般单独放在最后一张幻灯片里，前面用 `---` 分页）。
- 和 `:::stat:::` 一样，围栏内**第一段文字**会被当作大标题自动放大加粗，后面的段落作为说明文字——**不要用 `#`/`##` 标题写法**，因为开启 `breakOnHeadings` 时，一级/二级标题会在围栏语法解析之前就先把幻灯片切开，导致围栏失效。

**示例**:
```markdown
---

:::closing

谢谢观看

欢迎交流、批评指正

pengwb8@gmail.com

:::
```

### 19. 页眉 Logo

在文档任意位置（建议放在最前面）单独一行写 `logo: 图片路径`，即可让每张幻灯片右上角显示这个 logo；该指令行本身会从正文中自动去除，不会显示出来（图片路径为裸 URL 时也会被正确识别并去除，不受 Markdeep 自动加链接影响）。

如果希望标题页（第一页）和各个一级标题（H1）开头的页面使用**不同**的 logo（比如首页放大图、内页放小图标），再加一行 `logo1: 图片路径`：

- `logo1:` 只用于标题页和 H1 开头的分页——如果没写 `logo1`，这些页面不显示 logo（即使写了 `logo:` 也不会显示）。
- `logo:` 用于其余的分页，包括以二级标题（H2）开头的分页。
- 路径可以是相对路径（相对于 HTML 文件）或完整 URL；图片默认固定显示在每页右上角，默认最大 4rem × 4rem。

**缩放与偏移**：在路径后面用空格加 `scale=`、`x=`、`y=` 参数，可分别调整 logo 的大小和位置（`logo:` 与 `logo1:` 的参数各自独立设置）：

- `scale=<数字>`：缩放倍数，默认 `1`（对应 4rem）。例如 `scale=1.5` 会把 logo 放大到 6rem。
- `x=<长度>`：水平偏移，在默认右上角位置基础上向右（正值）或向左（负值）平移，默认单位 `px`，也可写 `rem`/`em`/`%` 等。
- `y=<长度>`：垂直偏移，向下（正值）或向上（负值）平移，用法同 `x`。

**示例**:
```markdown
logo: images/company-logo-small.png scale=1.2 x=-10px y=6px
logo1: images/company-logo-large.png

**幻灯片标题**
副标题

---

## 第二部分

这一页会显示 logo（放大 1.2 倍，并向左下方偏移）。
```

### 20. 导出带标题书签的 PDF

浏览器自带的"打印"对话框（Cmd/Ctrl+P → 另存为 PDF）目前不提供生成书签的选项；但 Chrome 的无头（headless）模式支持 `--generate-pdf-document-outline` 参数，会根据文档里现成的一级标题（`#`，对应章节/大标题）和二级标题（`##`，对应每张幻灯片标题）自动生成两级 PDF 书签（大纲），不需要给幻灯片文档做任何改动。

项目根目录提供了 [export-pdf.sh](export-pdf.sh) 脚本封装了这个流程：

```bash
./export-pdf.sh 幻灯片.html [输出.pdf]
```

- 不传输出路径时，默认在同目录生成同名 `.pdf`。
- 脚本会自动查找本机的 Chrome / Chromium / Edge；如果安装在非常规位置，可以通过 `CHROME_BIN` 环境变量指定可执行文件路径。
- 生成的 PDF 用支持书签面板的阅读器（如系统自带的"预览"App、Adobe Acrobat）打开，即可在侧边栏看到可点击的标题大纲，点击书签会跳转到对应页面。

> 无头浏览器不会点击页面上任何按钮，所以像目录分栏切换按钮这类"只改当前页面状态、不改文档"的临时开关，导出的 PDF 里永远只会是默认状态。如果目录页想要多栏排版，请用上文"1. 自动导航与目录"里的 `toc-columns: multi` 指令代替点按钮，这样每次打开、以及导出 PDF 时都会是同样的排版。

标题页（`**标题** / 副标题`）和目录页本身不是 `#`/`##` 标题，不会出现在书签里，这是预期行为——书签对应的是正文里的章节和幻灯片标题。

## 🧩 围栏语法速查表

除了 `[incremental]`、`[!type]` 这类行内标记，本项目还有一套统一的 `:::类型 参数:::` 围栏语法：`:::` 成对出现，内容写在中间；嵌套时外层使用更多的冒号（`::::`、`:::::`……），结束标记的冒号数量要和开始标记一致。

| 语法 | 作用 |
|---|---|
| `:::columns N:M:::` | 多栏卡片布局，栏与栏之间用 `+++`（三个加号）分隔，`N:M` 是可选的宽度比例，最多 4 栏；带子列表的顶层列表项会自动变成卡片标题 |
| `:::listcolumn:::` | 大纲自动转多栏，每个一级列表项自动变成一栏（标题 = 条目文字，正文 = 子列表），不需要 `+++` 分隔 |
| `:::quote 作者:::` | 引用卡片，作者参数可省略 |
| `:::stat:::` | 数字/KPI 卡片 |
| `:::flow N:::` | 报刊式分栏，`N` 为栏数（可选，默认 2） |
| `:::flip 高度:::` | 翻转卡片，用 `+++` 分隔正反两面，高度参数可选 |
| `:::incremental:::` / `:::appear:::` | 块内顶级元素逐个点击揭示 |
| `:::appearN:::` | 指定揭示顺序（`N` 为数字，数字越小越先出现） |
| `:::appear-left::: / :::appear-right::: / :::appear-up::: / :::appear-scale:::` | 带方向的进场动效 |
| `:::incremental-flat:::` | 块内列表项逐个揭示（只对直接子列表生效，不递归） |
| `:::big::: / :::small::: / :::tiny:::` | 局部字号调整 |
| `:::closing:::` | 独立结束页/致谢页，整页居中并隐藏导航栏、页码、进度条 |

> **注意**：早期版本中的 `:::two-column`、`:::two-column-appear`、单个 `;;;` 分隔符等写法已被 `:::columns:::` + `+++`（三个加号）取代，请使用上表中的新语法；`;;;;;;`（六个分号）作为旧分隔符仍可继续使用，不会失效。如果幻灯片正文里直接写了裸 `+++`（没有任何 `:::columns:::` / `:::listcolumn:::` 围栏包裹），也会被自动当作分栏符处理，见上文"多栏卡片布局"一节的兼容写法说明。
