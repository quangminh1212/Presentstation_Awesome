# 📊 AI PPT Generator

An AI-powered **PowerPoint Presentation Generator** built with **Google Gemini API**, **Pexels API**, and **Streamlit**.  
This tool automatically creates structured presentation slides, adds relevant images, and lets you **download a ready-to-use PPTX file** in just a few clicks.  

---

## 🚀 Features
- 🔑 Uses **Gemini API** to generate slide content (titles, bullet points, conclusions).  
- 🖼️ Uses **Pexels API** to fetch free stock images.  
- 📑 Automatically creates **title, content, image, and conclusion slides**.  
- 📥 One-click **download of PPTX** file.  
- ⚡ Built with **Streamlit** for an interactive web UI.  

---

## 📂 Project Workflow
1. **User Input**: Enter topic, number of slides, and API keys.  
2. **Content Generation**: Gemini generates JSON-formatted outline for slides.  
3. **Image Generation**: Pexels provides matching images.  
4. **PPT Creation**: Slides are formatted using `python-pptx`.  
5. **Download**: Final `.pptx` file is saved and available to download.

## 🛠️ Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/Aaditya-Nanda/ai-ppt-generator.git
cd ai-ppt-generator
```

### 2. Create a Virtual Environment (recommended)
```bash
python -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the App
```bash
streamlit run app.py
```

The app will open in your browser at: [http://localhost:8501](http://localhost:8501)  

---

## 🔑 Getting API Keys

### Gemini API Key
1. Go to [Google AI Studio](https://aistudio.google.com/).  
2. Sign in with your Google account.  
3. Create an API Key and copy it.  

### Pexels API Key
1. Go to [Pexels Developers](https://www.pexels.com/api/).  
2. Create an account (free).  
3. Generate your API Key and copy it.  

You’ll need to paste both keys into the Streamlit app input fields.
