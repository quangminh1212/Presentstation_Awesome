# D-PPT Skill

一套面向中文商业汇报的 Codex Skill：把文本、PDF、DOCX、PPTX、XLSX、CSV、JSON 或 Markdown 整理为逐页脚本，使用图像模型生成整页 PNG，并封装为图片版 PPTX 与 PDF。

![D-PPT Skill 示例封面](./showcase/preview/cover.png)

## 示例成品

这是一套使用 D-PPT Skill 生成的 6 页项目介绍，完整经历了大纲确认、逐页脚本确认、质量探测、页面生成、文本 QA 和交付验证。

## 核心特点

- 先确认大纲和逐页脚本，再生成页面，避免直接产出不可控的整套幻灯片。
- 生成前真实探测当前图像接口可用的最高明确质量，并等待用户确认。
- 默认使用 `gpt-image-2` 和 `1536x864`，也支持显式生成 `3840x2160` 的 4K 页面。
- 支持从常见办公文件中提取源文字。
- 提供文本 QA、断点续跑、PDF/PPTX 封装和交付尺寸验证。
- 不使用 mock 或假图兜底；图像接口失败时会明确停止。

> 输出的 PPTX 是“每页一张整图”的稳定图片版，不是逐字逐对象可编辑的原生 PowerPoint。

## 安装

```bash
git clone https://github.com/Yang9547472171/D-PPT-skill.git ~/.codex/skills/xd-ppt
cd ~/.codex/skills/xd-ppt
python3 -m pip install -r requirements.txt
```

安装后重启 Codex，并通过 `$xd-ppt` 触发。

示例：

```text
使用 $xd-ppt，把这份产品方案做成一套 12 页中文汇报，最终输出 PPTX 和 PDF。
```

## 环境要求

- Node.js 18 或更高版本
- Python 3.10 或更高版本
- OpenAI Images API，或兼容 `/images/generations` 与 `/images/edits` 的接口

推荐通过操作系统的环境变量或可信的密码管理工具配置 `OPENAI_API_KEY` 与 `OPENAI_BASE_URL`，不要把真实值写进仓库文件或命令历史。

如果没有设置环境变量，生图和质量探测脚本会尝试读取当前 Codex 的 `~/.codex/auth.json` 与 `~/.codex/config.toml`。脚本只读取凭据，不会把凭据写入输出文件；发布日志或分享终端输出前仍应自行检查敏感信息。

## 工作流

1. 从用户材料中提取文字并确认最终受众。
2. 用户未指定页数时，先确认大纲。
3. 输出并确认逐页脚本。
4. 运行文本 QA。
5. 探测图像接口可用的最高明确质量，并等待用户确认。
6. 生成逐页 PNG。
7. 封装 PDF 和 PPTX。
8. 验证页数、图片尺寸与内嵌资源。

完整执行规则见 [SKILL.md](./SKILL.md)，视觉规范见 [references/visual-contract.md](./references/visual-contract.md)。
可直接参考 [examples/slides.example.json](./examples/slides.example.json) 编写逐页脚本。

## 常用命令

从文件提取文字：

```bash
node scripts/extract_source_text.mjs --input source.pdf --out source.txt
```

检查逐页脚本文字：

```bash
node scripts/qa_deck_text.mjs --input slides.json
```

探测当前接口质量：

```bash
node scripts/probe_image_quality.mjs \
  --out output/quality-probe.json \
  --image-out output/quality-probe.png \
  --size 1536x864
```

生成页面；建议先使用 `--dry-run` 检查提示词：

```bash
node scripts/generate_slide_images.mjs \
  --slides slides.json \
  --out-dir output/pages \
  --quality high \
  --dry-run
```

用户确认质量后，移除 `--dry-run` 进行真实生成。然后封装和验证：

```bash
node scripts/build_image_pdf.mjs \
  --images-dir output/pages \
  --out output/deck.pdf

node scripts/build_image_pptx.mjs \
  --images-dir output/pages \
  --out output/deck.pptx

node scripts/verify_deck_assets.mjs \
  --images-dir output/pages \
  --pdf output/deck.pdf \
  --pptx output/deck.pptx \
  --width 1536 \
  --height 864 \
  --expected-pages 12
```

## 安全与开源边界

- 不要提交 `.env`、API Key、Codex 本地认证文件或生成日志。
- 不要提交客户原始材料、真实 Logo、未脱敏数据或未经授权的交付文件。
- 公开示例及其生成页面应使用合成内容、自有内容或获得明确公开授权的内容。
- 图像生成结果及输入材料的使用应遵守相应模型服务条款和数据合规要求。
