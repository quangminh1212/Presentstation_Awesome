# 期末速成助手 / ExamCram

> **当前版本：v1.0.3** —— 完全离线、无需任何大模型或 API Key；支持 `.txt` / `.md` / `.pdf` / `.docx` / `.pptx` 与图片导入，扫描版 PDF / 图片可离线 OCR 识别文字；复习讲义 PPT 总页数硬上限 30 页；每套模拟卷独立导出 Word（卷面）+ PDF（答案）。**仅支持 Windows（64 位）。**

一款面向「期末突击复习」的 Windows 桌面应用（Python + tkinter）。把课程资料（上课 PPT / 过程考 / 期中考试等）导入后，一键完成 **离线知识点总结与重要度划分 → 三天复习计划 → 导出复习讲义 PPT → 生成模拟卷（Word 卷面 + PDF 答案）**。完全离线、**无需任何 API Key 或大模型**，开箱即用；导入支持图片 / 扫描版 PDF 的离线 OCR 文字识别。

> 应用窗口启动即最大化；导出的 PPT 每页文字均保证落在页面内、不溢出。

---

## 功能特性

- **① 资料导入**：支持粘贴文本 / 打开 `.txt` `.md` `.pdf` `.docx` `.pptx`，以及**照片 / 截图（`.png` `.jpg` `.jpeg` `.bmp` `.webp`）**。PDF 与图片均支持**离线 OCR**：扫描版 PDF（无文字层）会自动提示并逐页识别；图片经 RapidOCR（PP-OCR 中文模型）识别文字后填入；按「来源类型 + 标题」逐条添加（Word 提取正文与表格，PPT 提取每页文字并标注「幻灯片 N」）。OCR 在后台线程运行，带进度条与取消按钮；页数超过 200 会弹窗提示可能较慢。
- **② 智能总结**：用本地启发式算法把资料拆成带「重要度（高 / 中 / 低）」「类别」的知识点清单（**完全离线、不依赖任何大模型**），可在界面手动调整重要度。
- **③ 三天计划**：根据重要度自动生成 3 天冲刺复习计划。
- **④ 导出 PPT**：一键导出复习讲义（封面 + 重要程度总览 + 各来源重点页，按星级降序；单页放不下自动分页）。**总页数硬上限 30 页**，专为 3 天冲刺精简。内置 **20 套** 渐变主题背景可选。
- **⑤ 模拟卷**：生成「普通模拟卷」与「最终版」两套卷型（数量可分别设置）。普通卷含选择 / 填空(20×1) / 判断 / 简答 / 综合；最终版填空改为 2 分且题量更少。**每套独立成文件**：`科目_模拟卷N.docx`（卷面）+ `科目_模拟卷N_答案.pdf`（答案），互不合并。
- **⑥ 设置**：界面语言（简体中文 / English）、外观（亮色 / 暗色 / 跟随系统），即时生效、下次沿用。**已移除大模型接入选项，应用完全离线运行。**
- **离线模式**：总结与出题均由本地启发式算法生成（无需联网、无需模型），开箱即用；OCR 亦完全本地运行。

## 目录结构

```
exam_cram_app/
├── src/                  # 应用源码（tkinter 主程序 + 各模块）
│   ├── exam_cram.py      # 主程序：界面、工作流程编排
│   ├── ai_client.py      # 知识点总结（离线启发式）、出题蓝图
│   ├── backgrounds.py    # 20 套 PPT 主题背景生成
│   ├── ppt_export.py     # 复习讲义 PPT 导出（自动分页、≤30 页、20 套主题可选）
│   ├── exam_export.py    # 模拟卷 Word / PDF 答案导出（每套独立文件）
│   ├── i18n.py           # 中英文案
│   ├── theme.py          # 字体 / 主题样式
│   ├── plan.py           # 三天计划生成
│   └── assets/           # （运行时资源目录）
├── assets/               # 应用图标 app_icon.ico / 预览图（PPT 背景图运行时生成）
├── make_icon.py          # 重新生成应用图标（渐变底 + 学士帽 + 闪电 + L 徽章，跨平台）
├── create_shortcut.py    # 生成桌面快捷方式（仅 Windows，双击即最大化）
├── ExamCram.spec         # PyInstaller 打包配置（Windows → ExamCram.exe）
├── run_demo.py           # 演示流水线脚本
├── test_core.py          # 核心模块自测
├── generate_theme_previews.py
├── requirements.txt
└── README.md
```

## 运行（源码模式）

```bash
# 1. 安装依赖（Python 3.10+，tkinter 随 CPython 自带）
pip install -r requirements.txt

# 2. 启动
python src/exam_cram.py
```

> 源码模式下窗口图标需要 `src/assets/app_icon.ico`；若缺失会自动跳过，不影响功能。

## 打包为独立 exe

```bash
pip install pyinstaller
pyinstaller --noconfirm ExamCram.spec
# 产物：dist/ExamCram.exe（单文件、自包含，可拷到任意 64 位 Windows 直接双击运行）
```

打包后用 `create_shortcut.py` 在桌面生成快捷方式（已设置为双击最大化）。

## 导出文件说明

- `<科目>_复习讲义.pptx`：复习讲义（每页文字均落在页面内，≤30 页）。
- `<科目>_模拟卷N.docx`：第 N 套模拟卷卷面（N 从 1 开始）。
- `<科目>_模拟卷N_答案.pdf`：第 N 套对应答案。

默认输出目录为程序所在目录下的 `outputs/`，可在「⑥设置」中修改。

## 备注

- 应用**完全离线**，无任何大模型 / 网络依赖；所有总结、出题、OCR 均在本地完成。
