## 中文

### 📖 这是什么

PPT-Skill 是一个 **Codex Agent Skill**，它不是又一个"一键套模板"的 AI PPT 玩具，而是一条 **从需求调研到最终交付的完整内容生产流水线**。

你只需要给它一个主题，比如"Dify 企业介绍"，然后就可以去泡杯咖啡了。它会像一个真正的专家团队那样，自己跑完从**需求调研 → 资料搜集 → 大纲策划 → 逐页研究 → 设计稿生成 → PPTX 导出 → 演讲稿**的全流程。

### 🧠 核心理念

这套方法论来自 [Sandun](https://linux.do/t/topic/1782304) 在 Linux.do 分享的 PPT Agent 思路，核心洞察是：

> 市面上几乎所有 AI PPT 工具都犯了一个致命错误：你一输入主题，它就猴急地给你丢出一个粗糙大纲，然后用一堆现成的模板糊弄你。
>
> **但 PPT 的灵魂是内容，不是皮囊。** 想想我们自己做 PPT 的流程：是不是得先搞清楚"为谁做？做什么？达到什么目的？"

基于这个洞察，本 skill 把 PPT 生产拆成 **7 个阶段**，让 AI 像专业团队一样完成全流程。

### 🔄 七阶段流水线

```
┌─────────────────────────────────────────────────────────────────┐
│                        PPT-Skill 流水线                          │
├──────┬──────────────────┬───────────────────────────────────────┤
│ 阶段 │ 名称              │ 产出                                  │
├──────┼──────────────────┼───────────────────────────────────────┤
│  0   │ 上下文收拢        │ 已有资料清单、约束条件                   │
│  1   │ 需求调研          │ 任务澄清文档（为谁做、做什么、目的）       │
│  2   │ 结构化大纲        │ 页面清单 + 便利贴视图                    │
│  3   │ 逐页资料搜集      │ 每页独立资料摘要                        │
│  4   │ 页面策划稿        │ 每页内容 + 布局决策                      │
│  5   │ SVG 设计稿        │ 每页 SVG 代码（Bento Grid 布局）         │
│  6   │ PPTX 导出         │ .pptx 文件                             │
│  7   │ 演讲稿            │ 逐页自然口语讲稿                        │
└──────┴──────────────────┴───────────────────────────────────────┘
```

### ✨ 特性

| 特性 | 说明 |
|------|------|
| 🧑‍💼 **顾问式需求调研** | AI 像专业顾问一样先搜集资料、再追问关键问题 |
| 🔺 **金字塔原理** | 结论先行、以上统下、归类分组、逻辑递进 |
| 📌 **便利贴法大纲** | 每页 = 一张数字便利贴，可视化结构，拖拽调序 |
| 🔍 **逐页独立研究** | 不是搜一次总资料，而是按页面主题逐页检索 |
| 🎨 **Bento Grid 布局** | 7 种灵活卡片布局，由内容驱动而非模板驱动 |
| 🖼️ **SVG 交付** | 可导入 Office 2016+，可编辑、无损缩放 |
| 🎤 **演讲稿生成** | 逐页自然口语稿，倒逼检查逻辑连贯性 |
| ⚡ **快速模式** | 明确要求时可跳过追问，直接生成 |

### 📐 Bento Grid 布局系统

PPT-Skill 使用 **Bento Grid** 作为核心布局系统，提供 7 种灵活的卡片布局模式：

| 布局模式 | 适用场景 | 说明 |
|----------|----------|------|
| **单一焦点** | 核心观点、数据大屏 | 一张大卡片覆盖大部分区域 |
| **两栏对称** | 并列对比 | 50/50 等宽双卡片 |
| **两栏非对称** | 主内容 + 辅助 | 2/3 宽 + 1/3 窄 |
| **三栏布局** | 三步骤、三特点 | 三张等宽卡片 |
| **主次结合** | 核心 + 补充 | 居中大卡片 + 两侧小卡片 |
| **顶部英雄式** | 概览 + 细节 | 顶部宽幅 + 下方网格 |
| **混合网格** | 复杂多维信息 | 自由组合不同尺寸 |

### 🔧 各阶段详解

#### 阶段 0：上下文收拢

先看当前目录有什么，避免重复劳动：
- 检查已有资料（文档、PDF、Markdown）
- 确认是否允许联网检索
- 确认输出格式（仅 SVG / 需要 .pptx / 需要演讲稿）
- 检查是否有现成模板、品牌素材、配色方案

#### 阶段 1：需求调研与任务澄清

像专业顾问一样，先搞清楚真正的需求。必须确认：
- **主题**：PPT 讲什么
- **使用场景**：销售介绍 / 内部汇报 / 融资路演 / 技术分享 / 培训教学
- **目标受众**：技术团队 / 管理层 / 客户 / 投资人 / 学生
- **期望结果**：说服 / 通知 / 教学 / 激励
- **页数要求**：建议范围（通常 10-20 页）
- **风格偏好**：科技风 / 商务风 / 简约风 / 创意风

如果用户只给了一个标题（如"Dify 企业介绍"），AI 必须追问。

#### 阶段 2：结构化大纲（便利贴法）

运用**金字塔原理**构建演示逻辑：
1. **结论先行**：每个部分以核心观点开篇
2. **以上统下**：上层观点是下层内容的总结
3. **归类分组**：同层观点按逻辑分组
4. **逻辑递进**：内容按递进关系排列

每页用一张"便利贴"表示：页码、页面标题、关键信息点、页面类型。

#### 阶段 3：逐页资料搜集

不是搜一次总资料，而是按页面主题逐页独立检索：
1. 遍历大纲中的每一页
2. 为每页生成 2-3 个搜索关键词
3. 用搜索工具逐页搜集资料
4. 整理成每页的资料摘要

#### 阶段 4：页面策划稿

把内容组织成可设计的页面草图：
- **核心观点**：这页要传达什么
- **支撑信息**：2-4 个关键点
- **数据/案例**：具体的数据支撑
- **布局决策**：选择合适的 Bento Grid 布局
- **视觉元素**：是否需要图表、图标、图片

#### 阶段 5：SVG 设计稿生成

按布局规则生成高质量 SVG 页面：
- 画布尺寸：`viewBox="0 0 1280 720"`（16:9）
- 使用 Bento Grid 卡片布局
- 卡片间距：至少 20px
- 使用系统字体栈（避免字体缺失）

#### 阶段 6：PPTX 导出

使用 `scripts/svg_to_pptx.py` 将 SVG 打包成 .pptx：

```bash
python scripts/svg_to_pptx.py \
  --input_dir ./output/svg \
  --output ./output/presentation.pptx \
  --title "Dify 企业介绍"
```

#### 阶段 7：演讲稿

为每页生成 30-60 秒的自然口语化讲稿，标注重点、停顿、互动点。

### 📝 叙事结构模式

根据不同的演示场景，自动选择合适的叙事结构：

**说服型（路演/销售）**
```
封面 → 问题/痛点 → 解决方案 → 产品详情 → 数据/案例 → 竞争优势 → 团队 → 路线图 → 总结+行动建议 → 致谢
```

**通知型（汇报/进展）**
```
封面 → 目录 → 背景/现状 → 关键成果 → 数据分析 → 问题与挑战 → 下一步计划 → 总结 → 致谢
```

**教学型（培训/分享）**
```
封面 → 目录 → 概念介绍 → 核心原理 → 案例演示 → 实践要点 → 常见问题 → 总结 → 致谢
```

**激励型（愿景/文化）**
```
封面 → 愿景/使命 → 现状与机遇 → 核心价值观 → 成功案例 → 行动号召 → 致谢
```

## English

### What is PPT-Skill

PPT-Skill is a **Codex Agent Skill** that implements a multi-stage intelligent PPT generation pipeline. Instead of "one-click template filling," it follows a professional methodology to produce high-quality presentations through 7 distinct stages.

### The 7-Stage Pipeline

1. **Context Gathering** — Check existing materials and constraints
2. **Requirements Research** — AI acts as a consultant, asking key questions
3. **Structured Outline** — Pyramid Principle + Sticky Note visualization
4. **Per-Page Research** — Independent research for each slide
5. **Page Planning** — Content + layout decisions per page
6. **SVG Design** — Bento Grid layout system, 7 flexible patterns
7. **PPTX Export** — Package SVGs into editable .pptx files
8. **Speaker Notes** — Natural, conversational speaking script per page

### Key Features

- **Consultant-style requirements gathering** — AI researches the topic first, then asks targeted questions
- **Pyramid Principle** — Conclusion first, hierarchical structure, logical progression
- **Sticky Note visualization** — Each page = one digital sticky note for easy reordering
- **Per-page independent research** — Not one bulk search, but targeted per-slide research
- **Bento Grid layouts** — 7 flexible card-based layouts driven by content, not templates
- **SVG delivery** — Importable into Office 2016+, editable, lossless scaling
- **Speaker notes** — Natural conversational scripts that force logical coherence checks
