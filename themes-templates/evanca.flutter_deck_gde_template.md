# GDE Flutter Deck Template

A code-native recreation of the Google Developer Experts presentation template,
built with [Flutter](https://flutter.dev) and
[flutter_deck](https://pub.dev/packages/flutter_deck).

## Why This Exists

The goal is to make creating GDE presentations **vibe-codeable**.

Instead of manually arranging every element in Google Slides, describe the
presentation you want and collaborate with an AI coding agent to build, revise,
run, and visually validate it as Flutter code.

This makes presentations:

- Fast to create and iterate on through natural-language requests
- Consistent with the GDE visual language
- Reusable through parameterized slide layouts and shared widgets
- Version-controlled, reviewable, and easy to branch
- Able to include live Flutter widgets, animations, and interactions

## Agent Skills

The flutter_deck agent skills included in `.agents/skills/` are sourced from
the official [flutter_deck skills directory](https://github.com/mkobuolys/flutter_deck/tree/main/skills).
