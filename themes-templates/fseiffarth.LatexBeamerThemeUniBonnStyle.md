# LatexBeamerThemeUniBonnStyle

This is a template for latex beamer presentations which is adapted to the color style of university of Bonn Logo. 

## Usage

1. Download all the style files from this repository (.sty) and include \usetheme{UniBonn} in your latex file.
2. Copy the font folder [Exo 2](Exo_2) into the same directory as your latex file.
4. Download the University of Bonn logo from [here](https://confluence.team.uni-bonn.de/pages/viewpageattachments.action?pageId=187724137&sortBy=date&highlight=UNI_Bonn_Logo_Standard_RZ_XL+%281%29.png&&preview=/187724137/195815631/UNI_Bonn_Logo_Standard_RZ_XL%20(1).png) and replace the logo.png file in the repository with the downloaded logo.
5. Compile your latex file with XeLaTeX or LuaLaTeX to ensure proper font rendering.
