# ShanghaiTech-Beamer-Theme

This is an unofficial LaTeX beamer template for ShanghaiTech members.

This template mainly referenced https://github.com/tuna/THU-Beamer-Theme.

## How to use on Overleaf？

### 1. Open from Overleaf official templates website. (Recommend)

Go to: https://www.overleaf.com/latex/templates/shanghaitech-beamer-theme/tdqzswchqmjq

Click "Open as Template".

![](./images/README/pic_1.png)

The template will automatically compile.

### 2. Download from GitHub and upload .zip file to Overleaf

Click "Download ZIP" to save .zip source code.

![](./images/README/pic_2.png)

Click "New Project" and choose "Upload Project".

![](./images/README/pic_3.png)

Drag the .zip file into Overleaf.

![](./images/README/pic_4.png)

Click "Menu" and change the compiler to "XeLaTeX".

![](./images/README/pic_5.png)

![](./images/README/pic_6.png)

Then the template will automatically compile.
