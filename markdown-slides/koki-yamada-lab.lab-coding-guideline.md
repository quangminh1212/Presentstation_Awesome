
# 山田宏樹研究室のコーディングガイドライン

研究室メンバーがコーディングの基礎を身につけやすいように，GitHubの運用方法や，コードレビューの方法，ディレクトリ構造についてルールを設定しています．

## スライド資料

Marpを使ってスライド資料`main.md`を作っています．
