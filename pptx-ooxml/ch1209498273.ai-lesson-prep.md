> **English**: A full-pipeline lesson-preparation toolkit for university teachers — from timetable screenshots to course-plan docx, per-session lesson plans, and slide decks with speaker notes. Designed for AI coding agents (Claude Code / ZCode / your own agent), delivering exam-ready teaching documents in one consistent workflow.

面向 Claude Code / ZCode 等 AI 编程助手设计的**中文大学教师备课全流程技能包**：从课表截图解析到教学方案、逐次课教案、课件（.pptx）全链路贯通，口径一致、直接生成可提交的教务文件（Word / PPT / Excel）。

> 写给刚接到新课、马上要开课的大学教师：按照高校真实教学与教务规范设计，从排课对账到课件落盘一步到位。

## 它解决什么问题

大学教师备课与中小学完全不同：大纲自拟、教材自选、理论与实验排期交错、教务检查严密。通用 AI 工具的典型卡点是——生成的教案“缺乏真实课表约束、学时对不上、实验排在理论前面、思政仅贴标语口号、PPT 格式错乱且无讲稿”。

ai-lesson-prep 的针对性设计：

1. **真实排课约束**：以“周次”为统一时间单位解析课表，严格执行理论-实验对账，实验排期不早于对应理论，期末复习课自动压缩。
2. **思政三要素沉淀**：课程思政拒绝空洞口号，强制落地为“融入环节 + 展开讲解词 + 启发性讨论题”，一次课不超过一个点（≤8分钟）。
3. **全链路状态续接**：通过 `course-context.md` 维护课程基本信息、分班授课矩阵与备课进度，跨会话无需重复提供背景。
4. **确定性文件交付**：排课表导出带合并单元格的 Excel，教学方案与教案输出标准 docx，课件导出带讲稿备注且通过溢出检查的 pptx。

## 工作链路

```
课表截图 ──► 授课安排 Excel ──► 教学方案 docx ──► 教案 docx ──► 课件 pptx
            (univ-schedule)     (univ-plan)      (univ-jiaoan)   (univ-ppt)
                └──────────── course-context.md 课程档案贯穿全链路 ────────────┘
```

![pipeline](docs/images/pipeline.png)

每一步都由两层护栏把关：**生成前**读模板口径契约（骨架留删、占位符规则、配图规则），**交付前**强制渲染验收（docx/pptx → PDF → 逐页 PNG 检查空白页/占位符/溢出），外加 `run_smoke` 四链路动态回归与 `run_static` 静态断言。

## 技能组成

| 技能 | 角色 | 核心产出 |
|---|---|---|
| **`univ-lesson-prep`**<br>*(推荐·主技能)* | **全流程总编排**：根据当前备课阶段自动路由到具体能力规则书，统一管理数据契约与交付检查。 | `course-context.md` 全周期维护 |
| `univ-schedule` | **课表截图解析**：解析多班级课表网格，抽取课程编码、周次、星期、节次与地点。 | 分班授课表、16周课程 Excel 工作簿 |
| `univ-plan` | **学期教学方案**：将教学大纲学时映射到课表课段，理论-实验对齐，完成教学日历。 | 教学进度表（Word docx / 回填 Excel） |
| `univ-jiaoan` | **逐次课教案 v2**：以 2 学时为单位，生成双栏授课提纲、思政设计、内嵌示意图、作业及教学后记位。 | 逐次课教案 docx、知识点示意图 PNG |
| `univ-ppt` | **教学课件 v1.3**：依教案映射课件，一页一知识点，讲稿写入备注，内置白底主蓝设计系统与越界检查。 | 课件 pptx（含完整讲稿备注） |

配套 `references/` 资源：课程思政素材库（`sizheng-library.md`）、教学法菜单（BOPPPS/对分/翻转）、高校评审话语对照（OBE/两性一度）、标准模板（docx/pptx）及内置图标库（assets/icons/ 16 枚）。

## 安装方式

- **推荐安装：主技能（单文件夹全功能）**
  直接将 `skills/univ-lesson-prep/` 复制到你的宿主技能目录：
  - **ZCode / Claude Code**：复制到 `~/.agents/skills/` 或项目根目录 `.agents/skills/`
  - **Claude Code 插件**：通过插件源添加本仓库

- **模块化安装（按需单独安装）**
  如仅需特定环节，可从 `skills/` 单独复制对应子技能（`univ-schedule` / `univ-plan` / `univ-jiaoan` / `univ-ppt`）。各子技能已完成自包含封装。

## 依赖环境

使用本技能包前，请确保 Python 环境安装了所需基础库：

```bash
pip install -r requirements.txt
```

*(主要依赖：`python-docx`, `openpyxl`, `python-pptx`, `Pillow`, `matplotlib`)*

## 快速开始（新课备课全流程）

```
1. 课表解析
你：[发送课表截图] 帮我看看这学期《数据结构》怎么排的，A班和B班分别每周几上？
AI：（解析网格与课程编码 → 回显授课表与缺周统计 → 确认后生成 16周工作簿.xlsx 并写入 course-context.md）

2. 排教学方案
你：这是我的教学大纲（理论40学时、实验24学时），帮我把进度排进真实课表。
AI：（学时严格对账 → 理论按序展开、实验依理论进度紧随 → 确认后生成教学方案.docx 并回填 Excel）

3. 备单次课教案
你：备第5次课教案，内容是 2.4 顺序表的表示与实现。
AI：（生成双栏提纲、标注重点★难点★★ → 提取思政三要素 → 渲染内存布局示意图 → 确认后落盘教案）

4. 制作课件 PPT
你：根据刚生成的第5次课教案做课件 PPT。
AI：（给出 18~24 页逐页大纲 → 确认后用 ppt_kit 生成 pptx，讲稿写入备注 → 跑 qa_overflow.py 验证无溢出）
```

## 验证与回归

安装依赖后，可一键跑通并校验四条确定性交付链路（课表→Excel / 教学方案→docx / 教案配图→PNG / 课件→QA 校验）：

```bash
python evals/run_smoke.py            # 动态回归：四链路跑 fixture 校验产物
python evals/run_static.py           # 静态断言：双轨副本一致 / 规则书锚点 / 模板 v3 结构 / ppt_kit 页型备注 / 样板书目
# 或指定 venv：python evals/run_smoke.py --python <venv-python>
```

任一检查失败退出码非 0。测试夹具位于 `evals/fixtures/`（脱敏课表 JSON + 大表式教学方案模板，模板可由 `gen_fixture_tpl_dabiao.py` 复现）；`run_static.py` 把历次审计踩过的双轨漂移固化为回归护栏，改副本/模板/规则书后必跑。

## 全局红线

1. **国家标志红线**：素材严禁使用国旗、国徽等国家标志（含 emoji 形式），思政页采用中性图标。
2. **真实性红线**：不编造教材页码、不虚构实验数据，正式教案参考资料栏不列网页链接。
3. **后记留空**：教学后记只留【课后填写】，AI 绝不代填。
4. **先确认后生成**：长文档（进度表/教案/课件）一律先给逐页大纲或骨架，确认后再落盘。
