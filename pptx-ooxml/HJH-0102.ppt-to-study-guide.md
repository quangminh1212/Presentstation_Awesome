# PPT 转期末复习资料

AI Agent 开源技能，将任意 PPT/PPTX 转化为全面展开的期末复习资料 PDF。自动判断 PPT 类型（文字/图片/混合），并行提取内容，按章节展开知识点，输出专业排版的复习资料。

兼容多个 AI 编码助手：QoderWork、OpenAI Codex、Claude Code、Cursor、CodeBuddy 等。

## 功能

- 自动识别 PPT 类型：文字格式直接提取、图片格式并行视觉转录、混合型双路合并
- 每个知识点三段式展开：核心要点 + 详细解释（含公式推导） + 易错点
- 双路排版输出：LaTeX（ctex + xelatex，首选）或 Word（docx，备选）
- 彩色高亮框标注核心要点、易错点、关键教训
- 文末附高频考点速查表

## 安装

将整个仓库克隆到 AI Agent 的技能/指令目录中：

```shell
# QoderWork
git clone https://github.com/<your-username>/ppt-to-study-guide.git ~/.qoderworkcn/skills/ppt-to-study-guide

# 其他 Agent：克隆到项目目录，Agent 会自动读取对应的指令文件
git clone https://github.com/<your-username>/ppt-to-study-guide.git
```

## 多平台兼容

| AI Agent | 指令文件 | 说明 |
|---|---|---|
| QoderWork | `SKILL.md` | 技能主文件，包含完整工作流 |
| OpenAI Codex | `AGENTS.md` | 引用 SKILL.md 的适配器 |
| Claude Code | `CLAUDE.md` | 引用 SKILL.md 的适配器 |
| Cursor / CodeBuddy | `.cursorrules` | 引用 SKILL.md 的适配器 |

核心工作流统一维护在 `SKILL.md` 中，各平台的适配器文件仅做引用和快速索引，避免内容重复。

## 使用方式

在任意支持的 AI Agent 中说：

> 帮我把这个 PPT 转成复习资料

Agent 会自动读取对应的指令文件，引导完成以下流程：

1. 检测 LaTeX 环境，确定输出路径（LaTeX 优先，Word 备选）
2. 判断 PPT 类型（文字 / 图片 / 混合），选择提取策略
3. 提取全部幻灯片内容（markitdown / python-pptx / 并行视觉转录）
4. 按章节结构化，为每个知识点编号
5. 展开每个知识点（定义解释、公式推导、典型例子、易错点）
6. 排版输出（LaTeX 彩色高亮框 / Word 表格模拟高亮）
7. 编译为 PDF 并验证

## 依赖

- Python 3.10+
- `python-pptx`、`markitdown`、`Pillow`（图片压缩时需要）
- LaTeX 环境（可选，推荐）：TeX Live + ctex + xelatex
- 无 LaTeX 时：LibreOffice 或 pandoc（用于 Word 转 PDF）

## 注意事项

- 图片格式 PPT 转录质量依赖 AI 视觉能力，建议人工抽查关键页
- 数学公式在 LaTeX 路径下渲染最佳，Word 路径使用 Unicode 符号替代
- 知识点展开基于 AI 知识库，重要公式和定理建议与教材交叉验证
- 超星下载的 PPT 通常为纯图片格式，markitdown 提取为空属于正常现象
