# This is an AI-generated PPT project based on python-pptx and web crawlers
*Before running this project, make sure that the Python environment and the corresponding third-party libraries are installed*
```python
pip install PyQt5
pip install openai
pip install python-pptx
pip install requests
```

Next, a deepseek api_key is required. Of course, this project is not yet complete, so it is temporarily uploaded to the repository and will continue to be developed during the winter break. Currently, it can only achieve some very simple functions, such as inputting keywords to generate a ppt. This ppt is also very simple, with slides only containing background images and paragraphs. Of course, other approaches were also considered, such as having AI generate a markdown file and then feeding it to another website to generate a ppt according to a template, then downloading it, but that is for later.
