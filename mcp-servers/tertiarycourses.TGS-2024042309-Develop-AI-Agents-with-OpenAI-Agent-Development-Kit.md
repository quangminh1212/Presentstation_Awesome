## About the course

This practical course develops Python-based AI agents from their runtime contract through production assurance. Learners work with typed outputs, function tools, sessions, embeddings, vector retrieval, multi-agent handoffs, agents-as-tools, Model Context Protocol boundaries, guardrails, traces and evaluation evidence. The course title retains “Agent Development Kit”; the implementation uses the current official OpenAI Agents SDK terminology and interfaces.

## Learning outcomes

- Analyse AI applications using large language models and an observable agent loop.
- Establish LLM methodologies using embeddings, vector stores and retrieval-augmented generation.
- Identify and evaluate strengths, limitations and effectiveness of LLM applications and agent workflows.
- Assess product-development feasibility using tools, handoffs, agents-as-tools and Model Context Protocol.
- Evaluate and improve agent behaviour through guardrails, tracing, evaluation and model optimisation.

## Topics covered

1. OpenAI API and Agents SDK runtime
2. Retrieval-augmented generation agents
3. Multi-agent orchestration
4. Tools, MCP and product integration
5. Guardrails, tracing, evaluation and improvement
