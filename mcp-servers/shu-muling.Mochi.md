# 🎐 Mochi 麻糬 AI（1.1）

一个蹲在你电脑桌面上帮你干活的 AI 助手 🎐

> **🚀 只想用不想折腾？** 打开仓库的「发行版」页面，下载 `Mochi-打包版` 压缩包，解压双击 `Mochi.exe` 即用，无需安装 Python 或任何依赖。详见下方「📦 给非技术用户使用」。

**桌宠特性**：

- 🐾 桌面悬浮球，9 种动画状态（待机/挥手/思考/奔跑/跳跃/…），鼠标点击会挥手打招呼
- 🔀 桌面自由拖动，想放哪放哪
- 🎨 多主题切换（樱花/深色/更多），聊天窗口和卡片配色跟随主题
- 🔔 悬浮球活跃度可调，专注工作时静音
- 🖼️ 桌宠形象可自定义：去 [petdex.dev](https://petdex.dev/) 选一个，替换 GIF 即可

**AI 能力**：

- 💬 多轮对话，最多 8 轮工具自动调用，流式输出实时渲染
- 🧠 双层记忆：短期记忆（精简压缩）+ 长期记忆（跨会话记住你）
- 🔍 混合检索：向量语义 + 关键词 BM25 双路召回
- 📚 知识库 RAG：把文件丢进目录自动入库，问啥答啥
- 📄 一键生成 PPT / Word / 流程图 / HTML / 图片
- 📂 桌面文件自动读取：说「帮我看桌面上周报」就行
- 🔌 MCP 外部工具：接一个 Server 零代码注入新工具

> 📖 想看完整技术分析？请读 [Detailed introduction.md](file:///d:/桌面/Mochi/Detailed%20introduction.md)

## 📦 给非技术用户使用（打包版）

**最简单的方式**：从百度网盘下载 `Mochi-打包版` 压缩包，解压后即可使用。

### 三步上手

1. **下载压缩包**：[百度网盘下载链接](https://pan.baidu.com/s/1w60CqcQR1ruZRKE57436Tg?pwd=MULI)，提取码：`MULI`
2. **解压启动**：解压后双击 `Mochi.exe`

### 配置 API Key

1. 点击悬浮球 → 打开聊天窗口 → 点击右上角 ⚙ 设置图标
2. 在「基础配置」里填入你的 [通义 DashScope](https://dashscope.console.aliyun.com/) API Key
3. 点击保存 → 重启应用即可对话

> 💡 后续要换模型、配路径别名等，都在设置面板里改，不用再动文件。

### 常用操作

| 操作          | 说明                                                            |
| ----------- | ------------------------------------------------------------- |
| 换模型/API Key | 点击聊天窗口的 ⚙ 设置图标，在弹窗中修改                                         |
| 配置桌面路径      | 设置弹窗 → 路径别名 → 添加 `{"桌面": "你的桌面路径"}` → 开启"用户目录"存储              |
| 读取桌面文件      | 直接说「帮我看桌面上的周报」                                                |
| 生成文档        | 说「帮我生成一份成绩单 Word」                                             |
| 自定义桌宠       | 去 [petdex.dev](https://petdex.dev/) 选 GIF，替换 `data/img/` 下的文件 |

### 注意事项

- 首次使用**必须配置 API Key**，否则无法对话
- 修改配置后**需重启应用**才能生效
- 生成的文件默认存在应用内部，开启"用户目录"后才会存到桌面
- 聊天记录保存在 `data/chat_history.db`，删除此文件会清空历史

## ⚙️ 配置

所有配置统一存储在 `config.json` 中，支持两种修改方式：

**方式一：设置弹窗（推荐）** — 点击悬浮球菜单的「⚙ AI 助手」打开设置弹窗，可视化修改：

- API Key（带眼睛图标可显隐切换）
- 模型名称、Base URL、天气 URL
- 路径别名（动态增删，默认空，需手动配置桌面）
- MCP 服务地址（动态增删）
- 悬浮球活跃度、存储方式等
- 生成文件存储位置（默认应用内部，可开启存桌面）
- 短期记忆后端（SQLite 默认 / Redis 可选）

> ⚠️ **修改所有配置后需重启应用才能生效**

**方式二：直接编辑 config.json** — 也可以手动编辑文件：

```json
{
    "api_key": "你的通义 DashScope API Key",
    "weather_key": "你的天气 Key",
    "theme": "sakura",
    "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "default_save_user": false,
    "short_memory_backend": "sqlite"
}
```

敏感信息也可以通过 `.env` 文件或环境变量加载。

## ▶️ 启动 Redis（可选）

SQLite 是默认短期记忆后端，无需启动 Redis。如需使用 Redis 模式：

```bash
net start Redis        # Windows 服务方式
# 或
redis-server           # 直接启动
```

python main.py

## 🔌 二次开发

本项目完全开源，预留了多个扩展点，大部分只需改 `config.py`：

| 扩展点                     | 改哪里                                                                                                                                                |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **自定义 AI 人设**           | `llm/AI.py` 里 `system_content` 第一行，改成你想要的人格描述                                                                                                      |
| **自定义可访问目录（安全控制）**      | 设置弹窗 → 路径别名，或改 `config.PATH_ALIAS`，定义麻糬能读哪些目录（默认为空，需手动添加如"桌面"）                                                                                     |
| 多用户                     | `get_login_user` 接真实 token 校验                                                                                                                      |
| Queue → Redis Stream    | `config.USE_CONSUMER`                                                                                                                              |
| Milvus Lite → 远程 Server | `config.USE_MILVUS_LITE` + `config.MILVUS_URI`                                                                                                     |
| 换 Whoosh 为 ES           | 新写一个 `sparse_searcher` 接口                                                                                                                          |
| 加内置工具                   | 新写 `skill/xxx.py` + AI.py 注册                                                                                                                       |
| **接 MCP 工具（零代码）**       | 设置弹窗 → MCP 服务，或改 `config.MCP_URL` 填 MCP Server 地址                                                                                                  |
| 换模型                     | 设置弹窗 → 模型配置，或改 `config.py` 模型名                                                                                                                     |
| **切换主题**                | 聊天窗口主题切换按钮，持久化到 `config.json`                                                                                                                      |
| **自定义桌宠形象**             | 去 [petdex.dev](https://petdex.dev/) 选择喜欢的桌宠 GIF，替换 `data/img/` 下对应文件名即可（文件名需匹配：Idle/Waving/Review/RunLeft/RunRight/Running/Jumping/Waiting/Failed） |

详细说明见 [Detailed introduction.md](file:///d:/桌面/Mochi/Detailed%20introduction.md) 的「二次开发 & 扩展预留」章节。
