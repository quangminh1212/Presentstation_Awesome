# 📊 PPT 자동 생성기

> 엑셀·워드·PDF 파일을 넣으면, 회사 PPT 디자인 그대로 발표 자료를 자동으로 만들어주는 도구예요.

---

## 이게 뭔가요?

보고서를 PPT로 만들 때 이런 경험 있으시죠?

- 엑셀 데이터를 PPT에 하나하나 복사·붙여넣기
- 회사 템플릿 디자인이 흐트러져서 다시 맞추기
- 같은 작업을 매번 반복…

**이 도구는 그 과정을 자동으로 처리해줍니다.**  
엑셀(또는 워드·PDF) 파일만 주면, AI가 내용을 읽고 회사 PPT 양식에 맞게 슬라이드를 만들어줍니다.  
색상·폰트·로고 위치는 원본 템플릿과 **완전히 동일**하게 유지됩니다.

---

## 어떻게 작동하나요?

내부적으로 4명의 AI 직원이 팀으로 일합니다.

```
📥 파일 입력
    │
    ▼
🧑‍💼 팀장 (Orchestrator)   ← 전체 흐름을 지휘해요
    │
    ├── 📖 자료 분석가      ← 파일 내용을 읽고 정리해요
    ├── 🎨 슬라이드 설계사  ← 어떤 순서로 몇 장 만들지 계획해요
    └── 🔨 PPT 제작자      ← 실제로 PPT 파일을 만들어요
    │
    ▼
📤 완성된 PPT 파일
```

---

## 지원하는 파일 형식

| 입력 | 출력 |
|------|------|
| 엑셀 (`.xlsx`) | PPT (`.pptx`) |
| 워드 (`.docx`) | |
| PDF (`.pdf`) | |

## 설치 방법 (처음 한 번만)

### 1단계 — Python 설치 확인

이 도구는 Python이라는 프로그램 위에서 돌아가요.  
설치 여부를 확인하려면 **윈도우 검색창**에 `cmd`를 입력해 명령 프롬프트를 열고 아래를 입력하세요.

```
python --version
```

숫자가 나오면 설치된 거예요. 아무것도 안 나오면 [python.org](https://www.python.org/downloads/)에서 설치하세요.

---

### 2단계 — 이 프로젝트 내려받기

초록색 **`< > Code`** 버튼을 클릭 → **`Download ZIP`** 선택 → 압축 풀기

---

### 3단계 — 필요한 라이브러리 설치

압축 푼 폴더 안에서 명령 프롬프트를 열고 아래를 입력하세요.

```
pip install -r plugin/requirements.txt
```

설치가 완료될 때까지 잠깐 기다리세요.

---

### 4단계 — AI 열쇠(API 키) 설정

이 도구는 Anthropic의 Claude AI를 사용해요.  
사용하려면 **API 키**가 필요합니다.

1. [console.anthropic.com](https://console.anthropic.com) 에서 회원가입
2. API 키 발급 (`sk-ant-...` 형태)
3. 명령 프롬프트에 아래 입력 (키 값은 본인 것으로 교체)

```
set ANTHROPIC_API_KEY=sk-ant-여기에본인키입력
```

---

### 5단계 — 템플릿 파일 확인

이 레포에 포함된 `기본1.pptx` 가 디자인 기준 파일이에요.  
이 파일의 디자인(색상·폰트·로고)을 기준으로 PPT가 만들어집니다.

## 자주 묻는 질문

**Q. 디자인이 바뀌지 않나요?**  
A. 네, 색상·폰트·로고 위치는 `기본1.pptx` 원본과 완전히 동일하게 유지됩니다.

**Q. 엑셀에 시트가 여러 개 있으면요?**  
A. 시트별로 슬라이드 섹션이 만들어집니다.

**Q. 인터넷이 없어도 되나요?**  
A. AI 기능(슬라이드 설계) 때문에 인터넷이 필요해요.

**Q. 데이터가 외부로 전송되나요?**  
A. 슬라이드 구성을 결정할 때 Anthropic 서버로 내용 일부가 전송됩니다. 민감한 데이터는 주의하세요.
