# Переглядач слайдів

Показує HTML-файли з папки `slides/` як слайди з навігацією.

## Як відкрити

1. **Локальний сервер (рекомендовано):**

   ```bash
   npx -y serve .
   ```

   Або: `python -m http.server 8080`  
   Потім у браузері: http://localhost:3000 (або 8080).

2. **Файл:** можна відкрити `index.html` напряму; використовується фіксований список слайдів (slide1…slide14).

## Керування

- **←** / **→** або **пробіл** — попередній / наступний слайд
- Кнопки «Попередній» та «Наступний» у верхній панелі

Слайди мають бути в папці `slides/` (наприклад `slide1.html`, `slide2.html`, …).
