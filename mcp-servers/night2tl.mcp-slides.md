# Model Context Protocol (MCP) Slide Deck

A web-based slide deck that explains the Model Context Protocol (MCP) to engineers. This presentation covers the core concepts, architecture, benefits, and practical examples of MCP with a cyberpunk/hacker aesthetic.

## Overview

This presentation explains:

- What MCP is and the problems it solves
- The client-server architecture of MCP
- Key components (Tools, Resources, Prompts)
- Benefits of using MCP in AI agent development
- Code examples and real-world applications
- Current limitations and future work

## Features

- **Dark Mode Theme**: Cyberpunk-inspired dark interface with neon accents
- **Matrix Background**: Subtle animated background with falling matrix characters
- **Terminal-style UI**: Elements styled like terminal windows for a hacker aesthetic
- **Typing Animation**: Dynamic text typing effect on the title slide
- **Interactive Elements**: Hover effects and subtle animations
- **ASCII Art**: Text-based graphics for a retro tech feel
- **Responsive Design**: Works on mobile, tablet, and desktop screens

## How to Use

### Running the Presentation

1. Simply open the `index.html` file in any modern web browser.
2. No build steps or dependencies are required!

### Navigation

- **Arrow Keys**: Use the left and right arrow keys to navigate between slides
- **Space Bar**: Press space to advance to the next slide
- **On-screen Controls**: Click the arrow buttons at the bottom of the screen
- **Touch**: Swipe left/right on touch devices to navigate
